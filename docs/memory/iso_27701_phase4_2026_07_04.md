## What this is

Phase 4 completes the tenant-facing upload + template surface for
ISO 27701. Phase 3 wired 27701 as a citable framework in chat but
tenant uploads for 27701-shaped documents were still routed
through the LLM extractor path (slower, costlier, less
deterministic). Phase 4 gives most 27701 uploads a
pattern-matched fast path.

## The pattern (per-leaf auto-generators)

Two existing generators just needed a fresh run against the
now-registered 196 27701 leaves:

- **`scripts/generate_template_scaffolds.py`** → 196 markdown
  templates in `db/templates/` (one per 27701 leaf). Each carries
  frontmatter binding to `leaf_id`, structured `<<MUST item:X>>`
  markers matching the leaf's must_contain ids, and a `<<SHOULD>>`
  section per should_contain. All template_version=1 (auto-scaffold);
  can be promoted to v2 by hand-editing.
- **`scripts/generate_doc_mappings.py`** → 101 YAML files in
  `db/doc_mappings/` (one per doc-shaped 27701 leaf — procedure /
  policy / scope_note / arrangement). Filename fingerprint
  tokenizer derives search tokens from the leaf title.
- **`scripts/generate_register_yamls.py`** → 51 YAML files in
  `db/workbook_mappings/` (one per register-shaped 27701 leaf).
  Sheet-name fingerprints + column-to-MUST bindings.

**Zero interpretive work.** All 348 new files are generator output.
The single hand-edit was fixing 2 stale leaf ids in a pre-existing
`hr_security_policy.yaml` (unrelated to 27701 — the ids were stale
from an earlier catalog rename).

## Coverage

- **Templates**: 196/196 leaves (100%) — every 27701 leaf has a
  scaffold that renders in `templates_block` on chat with the right
  format (docx narrative / xlsx tabular per `_is_tabular` logic).
- **doc_mappings**: 98 leaves covered / 196 (50%). The generator
  targets doc-shaped evidence_types (procedure, policy, scope_note,
  arrangement) — 98 27701 leaves fit this shape.
- **workbook_mappings**: 49 leaves covered / 196 (25%). The
  generator targets register-shaped evidence_types (register, log,
  record family) — 49 27701 leaves fit.

Combined: **147 of 196 leaves (75%) have a pattern-matched upload
path.** The remaining 49 (program_review shape + some
applicable_scope + edge-case types) go through the LLM extractor
until a hand-authored mapping exists.
