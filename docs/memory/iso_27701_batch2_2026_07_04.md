## Scope

Batch 2 of the ISO 27701 Phase 2 arc — the largest of the three.
Covers everything that happens BETWEEN "conditions for collection"
(Batch 1) and "transfers" (Batch 3):

- **§A.7.3.x** subject rights (10 controls): obligations catalog,
  notice content + delivery, consent withdrawal, objection, ACR
  (access/correction/erasure), third-party notification, copy of
  PII (Art.15.3 + Art.20 portability), request handling umbrella,
  automated decisions subject-facing (companion to Art.22)
- **§A.7.4.x** privacy by design + default (9 controls): collection
  limitation, processing limitation, accuracy, minimisation
  objectives, end-of-processing delete/de-identify, temp files,
  retention, disposal, transmission controls
- **§B.8.3.1** processor obligations support (1 control)
- **§B.8.4.x** processor privacy by design (3 controls): temp files,
  return/transfer/dispose, transmission controls

23 × 4 = 92 leaves. All op_process 4-leaf spine.

## Bridges

**48 total** — 11 SUPPORTS (27701→27001) + 37 IMPLEMENTS (27701→GDPR
per Annex D Table D.1).

Critical SUPPORTS edges — where 27701 privacy augments an existing
27001 security control:

- **A.7.3.6 → A.8.10** — erasure right rides on top of information
  deletion
- **A.7.4.5 → A.8.10 + A.5.9** — end-of-processing uses information
  deletion + asset register reconciliation
- **A.7.4.7 → A.5.33** — PII retention schedules ↔ records retention
- **A.7.4.8 → A.5.28 + A.7.14** — PII disposal ↔ evidence handling
  disposal_record + secure disposal of equipment
- **A.7.4.9 → A.5.14 + A.8.24** — transmission ↔ information transfer
  + cryptography (the critical crypto bridge)
- **B.8.4.2 → A.5.19** — processor end-of-service ↔ supplier
- **B.8.4.3 → A.5.14 + A.8.24** — processor transmission mirror

IMPLEMENTS edges cover every subject-rights article
(Art.7 + Art.11-22) + accountability/security articles (Art.5, 25,
28, 30, 32).
