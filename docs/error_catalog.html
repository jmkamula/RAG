ARION-INSTALL-* — install.sh time

CodeSymptomCauseVerifyFix
ARION-INSTALL-001 install.sh fails at "System packages" step with dpkg lock error apt is held by another process (unattended-upgrades, package manager) sudo lsof /var/lib/dpkg/lock-frontend sudo systemctl stop unattended-upgrades or wait then re-run installer (idempotent)
ARION-INSTALL-002 psql fails with "role "arioncomply" does not exist" during schema apply postgres_preamble.sql did not run or transaction rolled back sudo -u postgres psql -c "\du" | grep arion sudo -u postgres psql -f deploy/postgres_preamble.sql with password vars set, then re-run install.sh
ARION-INSTALL-003 install.sh reports "pip install" failure on psycopg2 or chromadb Missing build tools (libpq-dev / build-essential) dpkg -l | grep -E 'libpq-dev|build-essential' sudo apt-get install -y libpq-dev build-essential python3-dev, then re-run install.sh
ARION-INSTALL-004 Schema apply fails with "syntax error at or near :" inside a DO block psql :'var' interpolation used inside DO $$ ... $$ — not supported Look for DO $$ ... with :' inside body in your modified SQL Refactor to SELECT format('SQL WITH %L', :'var') \gexec pattern (see deploy/postgres_preamble.sql for canonical shape)
ARION-INSTALL-005 Neo4j graph load fails with ClientError or connection refused Neo4j service still warming up (~30s cold start) curl -sf http://localhost:7474 Wait 30s then PYTHONPATH=. python3 enrichment/documents/load_to_neo4j.py
ARION-INSTALL-006 requirements.txt install fails with AppleInternal path errors requirements.txt was pip freeze'd on macOS with system-vendored packages grep AppleInternal deploy/requirements.txt Regenerate on target OS: pip freeze | grep -Ev 'python-apt|ubuntu-drivers' — Ship 47 rule
ARION-INSTALL-007 Chroma reindex fails with OOM or takes >15 min on first install Cold-cache embedding compute; ~5385 MUST items + ~1000 corpus docs free -h (expect >=4GB free); watch /tmp/arioncomply-chroma.log Ensure 4GB+ RAM free before install; reindex is one-shot — retry with PYTHONPATH=. python3 scripts/reindex_all.py

ARION-BOOT-* — API startup / lifespan

CodeSymptomCauseVerifyFix
ARION-BOOT-001 API service fails to start; systemd shows activating (auto-restart) loop .env unreadable by service user OR missing required var sudo -u arioncomply cat /data/arioncomply/.env | head then journalctl -u arioncomply-api -n 50 chmod 640 /data/arioncomply/.env && chown arioncomply:arioncomply /data/arioncomply/.env
ARION-BOOT-002 API 500 on first chat with "RAG pipeline failed" or Chroma connection refused Chroma service not running on :8000 lsof -i :8000 or ss -tlnp | grep :8000 sudo systemctl start arioncomply-chroma && sudo systemctl enable arioncomply-chroma
ARION-BOOT-003 API startup logs "LangGraph checkpointer connection failed" SESSIONS_DATABASE_URL misconfigured or arioncomply_sessions DB missing psql "$SESSIONS_DATABASE_URL" -c '\dt' Ensure sessions DB exists + checkpoints tables present; apply db/baseline/schema_sessions_baseline.sql
ARION-BOOT-004 API refuses to bind :8080 — "Address already in use" Another API process already bound (leftover manual start) lsof -i :8080 kill $(lsof -ti:8080) && sudo systemctl start arioncomply-api
ARION-BOOT-005 Import error on startup: ModuleNotFoundError: rag.intake or similar PYTHONPATH not set in service Environment (Ship 47 systemd shape) systemctl cat arioncomply-api | grep PYTHONPATH Add Environment=PYTHONPATH=/data/arioncomply to the unit; systemctl daemon-reload

ARION-RUNTIME-* — post-boot operations

CodeSymptomCauseVerifyFix
ARION-RUNTIME-001 Chat returns 401 with correct-looking API key Key not in api_keys OR is_active=false OR expired Check tenants.txt in diag bundle for api_keys row matching key prefix Provision a fresh key: PYTHONPATH=. python3 scripts/dev/create_tenant.py --add-key-to <tenant-uuid>
ARION-RUNTIME-002 Dashboard shows all controls as "Not assessed" Fresh tenant with no posture_controls rows yet In diag bundle tenants.txt: posture counts row shows 0 or missing tenant Upload evidence documents via /ui/arioncomply.html → Documents; OR seed via scripts/dev/create_tenant.py
ARION-RUNTIME-003 Upload succeeds but no findings appear in Stage-1 queue Doc format not recognized OR extractor timed out OR consensus rejected all candidates Check journal-api.txt for "extraction_status=failed" and evidence_group_id log lines Re-extract: curl -X POST /api/v1/admin/uploads/<id>/reextract; check intake_trace_log for drop reason
ARION-RUNTIME-004 Chat shows "[DRAFT]" label on every posture even after Stage-1 approval confirmation_status not being propagated (Ship 30'.b was the cross-tenant fix) psql -c "SELECT ref, finding, confirmation_status FROM posture_controls WHERE tenant_id=... LIMIT 5;" Ensure posture_loader SELECT includes confirmation_status column (Ship 30'.b); check rag/posture_loader.py:load_posture
ARION-RUNTIME-005 Chat latency >30s on first query of a session Cold posture cache + Chroma warmup + LLM cold start Second query same session should be <5s; check journal-api.txt for "posture_cache_miss=true" on first turn Expected on cold cache. Warm the cache before demo with a throwaway query. Long-term: Ship 45 posture warm-up arc
ARION-RUNTIME-006 Bridge footer missing from cross-framework answers xfw_nodes_list empty in resolver output; likely Neo4j bridge edges not loaded In diag bundle neo4j.txt: check IMPLEMENTS / SUPPORTS / DEMONSTRATES edge counts > 0 PYTHONPATH=. python3 enrichment/documents/load_to_neo4j.py to reload bridges
ARION-RUNTIME-007 Sweep timer skipping ticks — sweep_log has gaps Timer disabled, or unit failure systemctl list-timers arioncomply-sweep.timer --all sudo systemctl enable --now arioncomply-sweep.timer; check systemctl status arioncomply-sweep.service
ARION-RUNTIME-008 OTel traces not showing in Jaeger UI OTEL_ENABLED=0 or Jaeger service down In diag bundle env.redacted.txt: OTEL_ENABLED value; curl -sf http://localhost:16686 Set OTEL_ENABLED=1 in .env; sudo systemctl restart arioncomply-api arioncomply-jaeger
ARION-RUNTIME-009 Chat deep-link from dashboard opens dashboard landing instead of specific control SPA hash-route handler not applying (Ship 46 fix) Browser URL should be like /ui/arioncomply.html#dashboard?ref=A.5.15 Hard-reload; check _applyHashRoute() in static/arioncomply.html is present (post-46'.c)
ARION-RUNTIME-010 Session chat lost when navigating between UI modes localStorage persistence not active or Cache-Control missing on SPA HTML Chrome DevTools → Application → Local Storage: _arion_chat_history should be present Verify Cache-Control: no-cache on /ui/arioncomply.html response (Ship 46'.d)
