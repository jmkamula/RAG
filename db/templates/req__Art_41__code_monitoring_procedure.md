# Code Monitoring Body Procedure

<<DOC_CONTROL>>

> Art.41 governs the accredited body that monitors a code of conduct's compliance. Applies when the org IS the monitoring body. Very rare for typical controllers/processors

## What this template gives you

This template helps you document the procedures your organization follows as an accredited body monitoring compliance with a code of conduct under GDPR Article 41. It's designed for organizations that act as official monitoring bodies.

## When to use it

Use this template if your organization is formally recognized as a code monitoring body, which is uncommon for most data controllers or processors. Update the document whenever your monitoring procedures change or as needed.
