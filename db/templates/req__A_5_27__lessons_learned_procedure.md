# Lessons Learned from Information Security Incidents

<<DOC_CONTROL>>

> A.5.27 requires knowledge from incidents to be used to strengthen and improve information security controls, update risk assessments, refresh incident plans, and update training. The procedure documents capture, action assignment, pattern analysis, root-cause typing and feedback into the broader control framework. The lessons register, periodic program review and per-lesson improvement-action record are sibling leaves

## What this template gives you

This template helps you document and analyze lessons learned from information security incidents, making it easier to improve your security controls, update risk assessments, and enhance your training and response plans.

## When to use it

Use this template whenever you experience an information security incident, and update it as needed to capture new lessons or changes in your environment.
