# PII Accuracy + Quality Procedure

<<DOC_CONTROL>>

> §7.4.3 requires the org to maintain PII accuracy + completeness + currency throughout the lifecycle. Bridges to GDPR Art.5.1.d accuracy + Art.16 rectification. Cross-links to A.7.3.6 correction procedure.

## What this template gives you

This template helps you create a clear procedure for keeping personal information accurate, complete, and up to date, supporting both ISO 27701 and GDPR requirements. It's useful if you need to show how you manage and correct personal data.

## When to use it

Use this template whenever your organization needs to document how it maintains and updates personal information, especially if your activities match certain triggers. Review and update the procedure as needed to stay current.
